# btw 实现与验证约定

此文件记录目标方案，不代表所有功能已经完成。实现状态以代码和测试为准。

## 交互

设计批注逐条验收见 [design-acceptance.md](design-acceptance.md)，不要以画板中 agent 的“已完成”回复代替实现验证。最新入口要求：全局临时聊天在新开对话页右上角，不在左侧栏。

- 侧问与临时聊天可在原入口快速打开，模型、上下文在输入区调整；默认行为兼容现有版本。独立的临时聊天不要求工作区。
- 弹窗和侧边栏只是同一临时会话的两种视图：停靠、弹窗切换、收起不删除；显式结束或切回普通聊天时等待关闭清理。
- 多选消息送回来源会话草稿，不能覆盖已有草稿、跨会话误写或自动发送；需要会话作用域的插入 API 和修订校验。
- `on-demand` 只在用户授权的最近对话快照中提供只读工具检索，不声称可查询完整历史，也不写入主会话；无能力完成时必须明确报错。
- 用户进一步确认 `all / 全部对话` 独立模式：通过官方被动 `session.events` 分页读取指定来源、固定 cursor 的已记录用户/助手/工具文本；不含实时未提交输出及附件二进制。保留压缩前记录并标记边界，缺页、失败或容量不足直接拒绝，不降级。
- 完整历史缓存仅保存在内存，绑定连接代际、来源 ID 与 cursor，合并并发读取，限制大小和生命周期。重复请求先确认新 cut，再复用稳定序列化前缀；本次问题追加末尾。provider prompt cache 与本地缓存不同，只有服务返回 usage 才能认定实际命中。

## 模型与设置

模型支持宿主默认、当前父会话模型和自选 provider/model；找不到当前模型时明确报错，不静默替换。设置采用 host volatile Config 与前端 configForms，单次覆盖不修改宿主默认模型。适配具体 dsh 0.2.2-rc.1 API，仍需隔离环境验证。

## 临时存储与风险边界

`gpt-6.1-sol` 已审阅清理设计：仅识别当前 dsh 0.2.2-rc.1 默认 JSONL 实现及其默认 sessions 根目录；插件独占生成 UUID，创建前记录归属，清理时等待 dispose、校验目录/后端和符号链接、只删除该临时会话目录；失败保留恢复信息并向用户报错。自定义或无法确认的后端不猜测、不删除。用户已接受同用户恶意并发替换父目录的理论竞态，本方案不承诺安全擦除及消除其他日志、模型服务或备份副本。

无工作区不能回退到 home 并悄悄加载文件工具；独立聊天只加载所需的文本对话能力。实际验证见隔离测试结果，不使用用户真实会话。

## 验收

对照画布统一 dsh 原生 G2 圆角；在隔离 `DSH_HOME` 运行单元测试、宿主和文件清理 smoke，使用用户授权的 dsh `glm-5.3-flash` 做真实模型测试，并验证浏览器交互、深浅色和窄屏。只有功能与测试完成后才提交；不发布、不 bump。
