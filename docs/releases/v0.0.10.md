# v0.0.10 — 平稳切换临时聊天与工作区

## 更新

- 修复工作区投影暂时不一致时可能误判已选工作区的问题。
- 关闭原生临时聊天后，优先回到同一工作区的普通空白对话，再在后台清理临时会话；用户后续导航不会被迟到的恢复操作覆盖。
- 临时对话与普通对话切换时同步标准、创造等 Agent 模式，在临时对话中更改的模式也会带回普通对话。
- 临时会话的虚线标记改为不占布局空间的描边；模式控件加载期间以短时不可交互的视觉副本衔接，减少开关时的位移和闪烁。

## 验证与边界

- Windows 桌面版 dsh `0.2.2-rc.3`：验证同一工作区的临时聊天开启与关闭，以及标准模式进入临时聊天、切为创造模式后返回普通对话；未发送模型请求。
- Windows 桌面实测模式控件开、关各采样 40 帧：79 帧与基准像素完全一致，1 帧有 2 个像素各 1 级亮度差；结果限于本机窗口、DPI 和本次采样。
- 模式衔接副本在目标模式就绪、用户操作或超时后移除；不同宿主版本、窗口布局与慢速设备可能出现不同效果。
- 临时会话清理仅支持已验证的默认 JSONL 存储；逻辑删除不等于安全擦除，跨进程共享目录、断电恢复和共享附件不在保证范围。
