# v0.0.7 — 临时聊天退出与切换修复（桌面测试版）

GitHub 预发布测试版；本次不发布 npm。

## 修复

- 修复 `domain 'workspace' is closed`：清理回调不再缓存首次注入的 workspace/domain/sessions，宿主重载后使用当前有效服务。
- 修复开启期间依赖重载的混代调用；父/子作用域并发卸载时等待同一个关闭屏障，并在释放服务前完成本人资源清理。
- 修复插件重载后丢失关闭回执的问题；仅在永久拒写标记及无残留证据完备时确认清理成功，不删除未知会话、不把待清理记录视为成功。
- 修复工作区登记失败或登记期间卸载导致临时会话失去前端所有权、无法重试结束的问题。
- 修复快速切换会话/连接后的迟到开启结果仍登记工作区、打开临时会话的问题；统一异步边界上的导航和服务代次检查。

## 验证与边界

- 新增 12 项回归测试，覆盖后端服务生命周期、真实 Cordis 卸载及前端退出/切换竞态。
- 语法检查、全量 251 项测试通过；最后追加两项切换回归并修复后，相关 146 项检查通过。
- 隔离安装版 dsh `0.2.2-rc.1` Web 宿主验证真实插件重载、重复关闭回执，以及本人 JSONL、独占 workspace、恢复记录清理；永久拒写标记按设计保留。
- 本轮未重做 Windows/macOS 桌面真机验收，供桌面端测试；仍要求 dsh `0.2.2-rc.1` 默认存储。逻辑删除不是安全擦除，共享附件、跨进程共享目录及断电恢复不在本次保证范围。
