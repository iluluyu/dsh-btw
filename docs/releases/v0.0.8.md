# v0.0.8 — 临时聊天工作区与生命周期修复

此版本包含此前仅在 GitHub 测试的 v0.0.7 修复。

## 修复

- 修复临时聊天选择工作区时可能反复返回选择器的问题：等待未归属的空白页完成选择，独立选择不再累计重断言次数。
- 桌面空白页优先继承可用的默认或最近工作区；没有可用工作区时可先选择临时聊天，再通过宿主选择工作区。
- 修复临时聊天开启、退出和工作区切换期间的导航竞态；过期会话在后台清理，不阻塞新的选择。
- 修复宿主服务重载后的临时会话清理、关闭回执和生命周期问题，并保留未完成清理所需的恢复记录。
- 保持受保护的临时会话存储路由跨配置重解析生效，并修复大 inode 身份比较的精度问题。

## 验证与边界

- 客户端回归覆盖选择器投影延迟、独立选择以及持续导航冲突的有限重试。
- Windows 桌面版实测开启临时聊天并连续选择默认工作区，未发送模型请求；未在真机强制制造所有投影竞态。
- 原生临时聊天清理仍以 dsh `0.2.2-rc.1` 默认 JSONL 存储为支持边界。逻辑删除不是安全擦除，跨进程共享目录、断电恢复及共享附件不在保证范围。
