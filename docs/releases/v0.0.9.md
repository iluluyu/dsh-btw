# v0.0.9 — 适配新版 dsh 会话服务

## 修复

- 支持 dsh `0.2.2-rc.3` 的默认 JSONL 会话存储，保留 `0.2.2-rc.1` 的支持和旧版临时会话恢复记录。
- 等待临时会话缓存保护后端注册成功，再自动配置有效路由；适配器初始化失败时，普通会话继续使用宿主原有的存储路由。
- 在恢复原生临时会话记录前校验会话存储和缓存适配器的宿主版本；混用版本时保留记录，修复版本后可重试。未知版本拒绝创建临时会话。
- 修复 Windows 诊断脚本对短路径和子进程清理的处理。

## 验证与边界

- Linux Web：dsh `0.2.2-rc.1` 和 `0.2.2-rc.3` 真实宿主普通会话创建、临时会话创建与清理，以及配置重解析和多次原生临时会话回归。
- Windows 桌面版 `0.2.2-rc.3`：实际打开并关闭上一版兼容修复的 btw 原生临时会话，确认对应会话目录和恢复记录已清理；最终 `0.0.9` 包在 Windows Web 宿主验证了临时会话创建与清理。未发送模型请求。
- 若曾手动配置 `session_projcache: btw-native-json`，请移除该用户配置，让插件管理有效路由。自定义后端和未经验证的宿主版本仍会拒绝临时会话；逻辑删除不等于安全擦除，跨进程共享目录、断电恢复和共享附件不在保证范围。
