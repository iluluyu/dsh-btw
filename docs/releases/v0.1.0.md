# v0.1.0 — 按需引用、补读与独立入口

`0.1.0` 收录两轮功能改动：入口与窗口行为的重构，以及按需引用的补读和流式思考的稳定性。

## 更新

### 入口与窗口

- 输入框按钮、`/btw`、右上角入口分别独立开关，各自设置打开位置（输入框上方 / 右侧栏 / 浮动小窗），不再共用一套设置；旧的共用配置会被迁移并保持原行为。
- 主页「临时聊天」开关从入口设置中独立出来，关掉入口不影响临时聊天。
- 在输入框上方、浮动小窗、右侧栏之间切换时保留草稿、已有聊天和侧栏标签状态；从小窗进入 DSH 原生全屏后，退出回到原窗口。
- 适配 dsh `0.2.2-rc.5`：移除首发注入的本地输入框，显式打开时恢复原生 Session 与原生 composer。

### 按需引用与补读

- 按需引用在发送时按固定切点检索来源会话，首轮最多引用四段原文；引用可在问题下方展开核对，来源角色一并显示。
- 模型可在需要时通过 `btw_read_context` 补读当前来源切点附近的相邻消息，读取范围与次数受限，实际补读以「补读」标签单独展开，不混入正式回答或引用。
- 来源切点、工具调用上限、未授权邻接候选的遮蔽、注入上下文与中断输出的排除都有回归覆盖。

### 流式思考

- 思考区在流式活动的空档保持展开并继续显示原文，不进入正式推理字段；最终回答后旧思考仍可展开核对。
- 移除每次消息更新都直接跳到末尾的逻辑，改为按内容与视口尺寸触发原生平滑滚动：用户上滚后停止跟随，滚回末尾恢复；开启「减少动态效果」时直接定位。
- 用流内 503 触发模型重试时，同一个已展开的思考区保留原文，重试的思考与正式思考、回答彼此分离。

## 验证与边界

- `npm run check` 通过，`npm test` 327 项全部通过。
- 隔离 DSH rc.5 + Chromium + 环回 SSE 存根模型的真实浏览器验收：按需引用（一次模型请求、只收到命中原文）、`--supplement`（首轮不含候选邻文，补读只读相邻消息）、`--scroll`（上滚位置稳定、回末尾恢复跟随）、`--retry`（重试期间思考不丢、不混入回答）四种场景全部 PASS。测试只用合成会话与合成内容，未请求真实模型。
- 记录与截图见 [log.md](../verification/log.md) 与 `docs/verification/on-demand/`。
- 临时聊天清理仅支持已验证的默认 JSONL 存储（dsh `0.2.2-rc.1` / `0.2.2-rc.3` / `0.2.2-rc.5`）；逻辑删除不等于安全擦除，跨进程共享目录、断电恢复与共享附件不在保证范围。
- macOS 仍只有平台注入测试覆盖，没有真机验收。
